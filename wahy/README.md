# وحي — واجهة تفسير ابن كثير

موقع ثابت (static SPA) يعرض القرآن الكريم مع تفسير ابن كثير، بلا خادم — بياناته JSON مولّدة من المكتبة المحلية.

## التشغيل

```
cd web && python3 -m http.server 8777
# ثم http://localhost:8777
```

## المميزات

- الرئيسية: بطاقات الـ114 سورة + بحث بالعربية/الإنجليزية/الرقم.
- صفحة السورة بوضعين: «قائمة الآيات» (بطاقة لكل آية) و«المصحف» (نص عثماني متصل بعلامات آية) — الضغط على أي آية يفتح تفسيرها.
- لوحة تفسير منزلقة تعرض نطاق الآيات المجمّعة، نص الآية، والتفسير كاملاً بلا تكرار.
- روابط عميقة: `#/s/2`، `#/s/2/mushaf`، `#/s/2/a/255` (تفتح التفسير مباشرة).
- وضع ليلي/نهاري محفوظ في localStorage.
- بيانات: web/data/index.json + web/data/surah/<n>.json (مولّدة بـ build.py من مكتبة QUL + تفسير ابن كثير المنظّم).

## إعادة بناء البيانات

```
python3 web/build.py   # يقرأ /Users/devin/wahy-data + data-normalized/tafsir-ibn-kathir
```
