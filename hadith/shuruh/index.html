خلاصة البحث: مصادر شروح الحديث الرقمية

تقييم ميداني لسبعة مستودعات وخدمات تقدم نصوص الشروح بصيغ قابلة للاستهلاك البرمجي — مرتبة من الأجمل فأنظف إلى الأدنى

الخلاصة بجملة

لا يوجد مصدر واحد يجمع نصوص الشروح الكاملة مع فهرسة علائقية 1:1 بالحديث؛ فالمطولات التراثية (فتح الباري وإخوتها) مهيكلة بالصفحات والأبواب لا بأرقام الأحاديث، والخدمات المفهرسة بالحديث (HadeethEnc) تقتصر على نصوص مهذبة مختصرة. التوصية: معمارية هجينة من ثلاث طبقات — مفصلة في الأسفل.

الترتيب التفاضلي للمصادر السبعة

1Shamela4_Full_DB على HuggingFace نظافة 9.5/10

قسم شروح الحديث كاملاً بصيغ JSONL+JSON (~2.1GB): فتح الباري، شرح النووي، عون المعبود، تحفة الأحوذي، إرشاد الساري، مرقاة المفاتيح، فيض الباري — بملفات manifest وpages وtoc لكل كتاب.

السبعة كلهم مغطاةملكية عامة، استخدام حرتحميل مجمع Git LFSفهرسة بالصفحة والجزء وشجرة الأبواب
المصدر: AuthenticIlm/Shamela4_Full_DB

2واجهة HadeethEnc (إسلام هاوس) نظافة 10/10

REST API بصيغة JSON مع Excel وPDF (~200MB) — الربط العلائقي الوحيد الكامل 1:1 بين الحديث وشرحه ومفرداته وفوائده، بترخيص مصرّح للاستخدام البرمجي والذكاء الاصطناعي.

فهرسة 1:1 كاملةترخيص AI صريحشروح مهذبة مختصرة لا مطولات
المصدر: hadeethenc.com/api/v1

3وسيط الدرر السنية (dorar-hadith-api) نظافة 8.5/10

وسيط Node.js/Express مفتوح المصدر (MIT) يحوّل موسوعة الدرر إلى JSON منقّى عند الطلب: شرح بمعرف sharh_id، بحث نصي في الشروح (t=3)، تخريج ورواة ورتبة الحديث.

كود MITشرح + تخريج + درجة100 استعلام/يوم — يحتاج تشغيلاً محلياً وتخزيناً مؤقتاً
المصدر: AhmedElTabarani/dorar-hadith-api

4مدونة OpenITI / KITAB نظافة 9/10

أكبر مدونة تراثية مفتوحة بمعايير أكاديمية (~350MB لقسم الشروح): فتح الباري والنووي وإرشاد الساري ومرقاة المفاتيح وعمدة القاري بمعرفات موثقة وفهارس صفحات معيارية (CTS).

نظافة أكاديمية مدققةCC BY-NC-SA 4.0يحتاج مفسراً لترميز mARkdown (### | وPageV01P003)لا ربط بأرقام الأحاديث
المصدر: منظمة OpenITI على GitHub + مكتبة openiti

5الشاملة المكتبية الرسمية نظافة 9.5/10

الأصل التاريخي: أكثر من 250 عنواناً في الشروح والحواشي، كل المطلوبة بأكثر من طبعة محققة — قواعد MDB/SQLite/BOK (~3.5GB) بجداول عناوين شجرية ونصوص صفحات.

أوسع تغطية إطلاقاًمجاني فردي ودعويلا حقل لترقيم الأحاديث — استخراج لاحق لازم
المصدر: shamela.ws الرسمية

6مكتبة إسلام ويب نظافة 9.5/10 (مشكول)

أدق فهرسة فقهية علائقية موجودة: فقرة الشرح مرتبطة صراحة برقم الحديث (bookhad) والباب والصفحة والجزء — لكنها HTML ديناميكي مغلق بلا واجهة ولا رخصة سحب.

أفضل ربط حديث↔شرحتشكيل كاملحقوق محفوظة — كشط محدود فقط
المصدر: islamweb.net (غير رسمي عبر alighamdan/islamweb.net)

7المكتبة الوقفية 3/10 برمجياً

أوثق الطبعات المحققة مصورة PDF (~15GB): فتح الباري بتحقيق ابن باز والفاريابي والأرناؤوط وغيرهم — للتوثيق والمراجعة البصرية لا للاستهلاك الآلي.

أدق الطبعات تاريخياًPDF مصور — يتطلب OCR عالي الخطأ
المصدر: waqfeya.net

المعمارية الهجينة الموصى بها لباب الحديث

الطبقة 1 — الاستدلال السريع والمعاني المباشرة

HadeethEnc API مصدراً أساسياً للأحاديث المشهورة: متن مشكول + مفردات غريبة + فوائد + شرح موجز، بمعرف حديث موحد ككيان رئيسي.

الطبقة 2 — الاسترجاع التراثي المعمق

Shamela4_Full_DB مخزناً رئيسياً للمطولات: قراءة pages.jsonl بربطها بشجرة الأبواب toc.jsonl، تقسيم النصوص كتلاً دلالية، ورصد مواضع الأحاديث داخل الشرح بتعابير نمطية («قوله:»، «وفيه حديث فلان») وربطها بمتون الطبقة الأولى.

الطبقة 3 — التوثيق والمطابقة المرجعية

OpenITI وإسلام ويب مرجعيتي تحقق: مطابقة أرقام الأجزاء والصفحات المطبوعة وتخريج الأسانيد وتراجم الرواة عند بناء بطاقات العرض التفصيلية.
